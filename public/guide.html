Главные правила безопасности и файл .env

Как устроена безопасность секретных ключей и почему они никогда не должны попасть в чужие руки.

Где НЕ ДОЛЖНЫ быть пароли:

Подготовка VPS и установка Coolify

Подойдет любой недорогой VPS с ОС Ubuntu 22.04 LTS или 24.04 LTS (от 2 GB RAM).

1

Подключение к VPS по SSH

Откройте терминал на компьютере (PowerShell на Windows) и подключитесь под root:

ssh root@IP_ВАШЕГО_СЕРВЕРА
2

Обновление системных пакетов

apt update && apt upgrade -y
3

Установка панели управления Coolify в 1 команду

Выполните официальную команду установки Coolify:

curl -fsSL https://cdn.coolify.io/coolify/install.sh | bash
ℹ️ Установка занимает около 2–3 минут. По завершении в терминале появится ссылка:
👉 http://IP_ВАШЕГО_СЕРВЕРА:8000 (например: http://194.87.123.45:8000).
Откройте её в браузере и создайте аккаунт главного администратора Coolify.

Настройка вашего домена (DNS A-записи)

Как привязать ваш купленный домен (например, moedomik.ru) к VPS и получить бесплатный SSL-сертификат.

1

Добавление DNS A-записей у регистратора домена

В личном кабинете, где куплен домен (Reg.ru, Beget, TimeWeb, Cloudflare и др.), откройте раздел «Управление DNS» и добавьте следующие A-записи:

Тип записи Имя / Хост (Subdomain) Значение (IP) Назначение
A @ (или пусто) IP_ВАШЕГО_СЕРВЕРА Основной домен сайта (https://moedomik.ru)
A www IP_ВАШЕГО_СЕРВЕРА Домен с www (https://www.moedomik.ru)
A pb (опционально) IP_ВАШЕГО_СЕРВЕРА Субдомен админки PocketBase (https://pb.moedomik.ru)
2

Указание домена в Coolify и автоматический выпуск SSL

В Coolify в настройках сервиса app в поле Domains укажите адрес с https:
https://ваш-домен.ru
Coolify сам автоматически выпустит бесплатный SSL-сертификат Let's Encrypt и продлит его в будущем!

3

Вставка домена в переменные окружения

Укажите ваш домен в переменной BASE_URL (без слэша на конце!):
BASE_URL=https://ваш-домен.ru
Эта ссылка используется сайтом для генерации ссылок календарей iCal для Авито, ссылок на фото и ботов.

Слайд 5 из 10 • ЭТАП 3

База данных PocketBase (Где находится и как открыть)

Все о встроенной базе данных: хранение файлов, прямой вход в панель управления и первый запуск.

🌐

По какой ссылке открывается?

Админка PocketBase доступна по адресу:
http://IP_ВАШЕГО_СЕРВЕРА:8090/_/
*(Или по субдомену: https://pb.ваш-домен.ru/_/)*.

💾

Где хранятся данные на VPS?

Вся база данных SQLite и загруженные фотографии хранятся на сервере в папке ./pb_data. При перезагрузках или обновлениях сайта данные не пропадут.

🔗

Связь с сайтом Node.js

Внутри Docker контейнер сайта связывается с PocketBase по внутренней сети по адресу:
POCKETBASE_URL=http://pocketbase:8090

🔑 Первый вход в PocketBase: при первом переходе по ссылке http://IP_СЕРВЕРА:8090/_/ введите Email и пароль супер-админа — такие же, какие вы укажете в переменных POCKETBASE_ADMIN_EMAIL и POCKETBASE_ADMIN_PASSWORD.

Загрузка проекта в GitHub и выбор Docker Compose

Связываем ваш приватный репозиторий с панелью Coolify.

🐙

1. Создайте репозиторий на GitHub

Перейдите на github.com/new, выберите Private (Приватный) и назовите его (например: rental-platform).

git init git add . git commit -m "Initial commit" git branch -M main git remote add origin https://github.com/ВАШ_ЛОГИН/rental-platform.git git push -u origin main
🚀

2. Создание ресурса в Coolify

1. В Coolify: Projects → выберите проект → + Add New Resource → Docker Compose.
2. Подключите ваш репозиторий GitHub. Coolify автоматически считает готовый файл docker-compose.yml из корня проекта.
3. Перейдите во вкладку Environment Variables для ввода настроек.

Инициализация базы данных (1 команда)

В проект встроен скрипт авто-создания схемы и начальных данных.

🚀

Запуск команды инициализации базы

В Coolify откройте сервис app → вкладка Terminal и выполните:

npm run setup:db

Или на сервере через SSH: docker compose exec app npm run setup:db

📦

Что сделает эта команда:

  • Создаст все 9 коллекций PocketBase (домики/квартиры, цены, гости CRM, брони, медиа, онлайн-чат, конфиг, iCal);
  • Импортирует конфигурацию и тексты сайта;
  • Создаст 4 готовых демонстрационных объекта с описанием, ценами и фото!
✨

Результат для покупателя:

Сайт сразу откроется с работающими карточками объектов, интерактивным калькулятором бронирования и формой заявок. Ничего вручную в базе настраивать не придется!

Уведомления: Telegram и МАКС Мессенджер

Мгновенное получение заявок и прямая переписка с гостями с сайта.

💬

МАКС Мессенджер (max.ru Bot API)

В платформу встроен сервис для МАКС Мессенджера:
1. Зарегистрируйте бота на платформе max.ru;
2. Вставьте токен бота в MAX_BOT_TOKEN;
3. Вставьте ID пользователя администратора в MAX_CHAT_ID.
Как это работает: когда гость пишет в живой чат на сайте, сообщение моментально приходит администратору в МАКС Мессенджер прямо на телефон, и администратор может сразу ответить гостю!

🤖

Telegram-уведомления

1. Создайте бота в @BotFather, скопируйте токен в TELEGRAM_BOT_TOKEN;
2. Узнайте свой ID через @userinfobot и вставьте в TELEGRAM_CHAT_ID;
3. Обход блокировок в РФ: в папке cloudflare-worker/ готов бесплатный ретранслятор для стабильной доставки заявок.

📁 Все 10 разделов административной панели

Каждый раздел решает конкретную бизнес-задачу управления платформой аренды. Все ссылки работают прямо в браузере после входа под логином и паролем:

Полный функционал управления
🏡 Управление объектами /admin/cabins.html

Каталог всех домиков, квартир, апартаментов, бань или гаражей. Добавление новых карточек, настройка вместимости (взрослые/дети), площади, спальных мест, фотогалереи, удобств, правил проживания и привязка персональных iCal-ссылок синхронизации с площадками.

📅 Бронирования и шахматка /admin/bookings.html

Наглядная интерактивная шахматка занятости по всем объектам на одном экране. Журнал заявок со статусами (Новая, Подтверждена, Оплачена, Завершена, Отменена), контакты клиентов, расчет сумм и кнопка быстрого создания бронирования вручную (для звонков и повторных гостей).

🏷️ Календарь цен и тарифов /admin/prices.html

Гибкое ценообразование: базовая суточная цена, повышенные тарифы выходных дней (Пт, Сб, Вс), индивидуальные цены на праздничные даты и сезоны, настройка минимального срока проживания и блокировка выбранных дат (статус CLOSED).

💬 Онлайн-чат с гостями /admin/chats.html

Живое двухстороннее общение с посетителями сайта в реальном времени. Поддержка передачи текста, фотографий и видео. Все сообщения моментально дублируются администратору в МАКС Мессенджер (max.ru) и Telegram!

👥 CRM (База клиентов) /admin/crm.html

Карточки всех гостей с историей их проживаний, телефон, email, никнеймы в мессенджерах, общая сумма оплат (LTV), персональные заметки администратора и учет предпочтений постоянных гостей.

📊 Аналитика и доходы /admin/analytics.html

Показатели финансовой эффективности бизнеса: выручка по месяцам, средний чек бронирования (ADR), процент загрузки номерного фонда (Occupancy Rate), статистика источников броней и конверсия заявок.

🎨 Конструктор Главного экрана (CMS без кода) /admin/mainpage.html

Полноценный визуальный редактор всего сайта без правок в коде! Позволяет полностью переделать сайт под любой бизнес (квартиры, глэмпинг, бани, склады, прокат):

• Логотип: ввод текстового логотипа или загрузка файла SVG/PNG;
• Общий фон сайта: фото фона + ползунок затемнения (0–85%) под фирменный стиль;
• Главный блок (Hero): большой заголовок, фоновое видео/фото, описание;
• Бегущая строка: текст акций + точный регулятор скорости показа (сек/круг);
• Видео «О месте»: YouTube / VK / RuTube или mp4, автоплей без звука, обрезка секунд;
• «Почему здесь хорошо»: визуальный конструктор преимуществ с иконками Lucide;
• Теги каталога: метки фильтрации объектов («У воды», «С баней», «Семейный»);
• Карта территории: фото схемы базы + интерактивные карточки «Что рядом»;
• Отзывы гостей: добавление реальных отзывов с оценками и цитатами;
• Контакты и Карта: телефоны, адрес, соцсети и координаты Яндекс.Карт.
⚙️ Услуги и наполнение объектов /admin/settings.html

Справочник платных услуг для формы заявки (аренда бани, сибирского чана, мангала, трансфер, доп. уборка, прокат сап-бордов) и удобства объектов (Wi-Fi, кондиционер, фен, кухня, терраса).

💬🎨 Виджет чата и Темы /admin/chatwidget.html

Настройка внешнего вида онлайн-чата: акцентные цвета оформления, приветственное автосообщение для гостей, быстрые кнопки частых вопросов (FAQ) и режим автоответчика.

🔐 Вход и Сводка (Дашборд) /admin/login.html & /admin/dashboard.html

Безопасный вход с защитой по кукам и автоматическим перенаправлением в шахматку броней. Не забудьте секретную пасхалку для владельца: быстрый 6-кратный клик по логотипу в шапке главной страницы сайта для мгновенного перехода в админку!
