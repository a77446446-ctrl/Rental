# 🏢 Universal Rental Platform — Универсальная платформа онлайн-бронирования и управления арендой

> **Готовое коммерческое решение «под ключ»** для сдачи в аренду любых объектов:  
> **домиков, коттеджей, глэмпингов, квартир, апартаментов, бань, беседок, гаражей, складов и оборудования.**  
> Включает адаптивный клиентский сайт (PWA), встроенный живой чат для гостей с фото/видео, мощную панель администратора (CMS/CRM), синхронизацию с Авито и другими площадками (iCal), автономную базу данных PocketBase, уведомления в Telegram и МАКС Мессенджер.

## 🌟 Ключевые возможности проекта

### 1. Клиентская часть (Фронтенд PWA)
- **Мобильное PWA-приложение:** сайт работает как нативное мобильное приложение с поддержкой оффлайн-режима и сохранением в кеш.
- **Интерактивное бронирование:** выбор дат в календаре, расчет ночей, выбор гостей, доплата за питомцев (с выбором вида животного), заказ дополнительных услуг (баня, чан, завтраки, квадроциклы).
- **Живой чат с поддержкой фото и видео:** гость может написать администратору прямо с сайта, прикрепить фото или видео.
- **Интерактивная карта Яндекс:** показывает территорию, маршрут и инфраструктуру рядом.
- **Галерея и карточки домиков:** панорамные фото, фильтры, теги удобств, описание и прозрачные цены.

### 2. Панель управления администратора (Admin CMS / CRM)
- **Вход в админку:** прямой по `/admin/login` или скрытый через **6 быстрых кликов по логотипу**.
- **Управление домиками (`/admin/cabins.html`):** добавление домиков, фото, настройка цен, правил размещения с животными и удобств.
- **Индивидуальные цены и даты (`/admin/prices.html`):** установка праздничных тарифов, скидок и закрытие дат на ремонт/уборку.
- **Заявки и бронирования (`/admin/bookings.html`):** подтверждение, отмена, архив, учет предоплат и контакты гостей.
- **CRM база гостей (`/admin/crm.html`):** история поездок каждого гостя, телефон, Telegram, персональные заметки.
- **Чаты с гостями (`/admin/chats.html`):** ответы клиентам в режиме реального времени.
- **Редактор главной страницы (`/admin/mainpage.html`):** изменение текстов, бегущей строки, видеоролика «О нас», отзывов и преимуществ без программиста!
- **Режим технических работ:** мгновенное включение заглушки сайта одной кнопкой в шапке панели.

### 3. Интеграции и надежность
- **Синхронизация iCal (Авито, Суточно.ру, Островок, Airbnb):**
  - Экспорт календаря: `https://ваш-домен/api/ical/export/{slug}.ics`
  - Автоматический импорт занятости каждые 30 минут — защита от двойных бронирований.
- **PocketBase (SQLite + Storage):** автономная встроенная база данных, потребляет всего от 30 МБ памяти, не требует сложных миграций PostgreSQL.
- **Уведомления в Telegram и MAX:** моментальные оповещения о новых бронированиях.
- **Cloudflare Worker Relay:** безопасный ретранслятор для стабильной доставки Telegram-уведомлений даже на серверах в РФ.

## 🛠️ Стек технологий

- **Бэкенд:** Node.js 20+, Express 4.x, Sharp (обработка изображений в WebP), Helmet, Cookie-Parser, Multer.
- **База данных и файлы:** PocketBase (v0.21+ / v0.22+).
- **Фронтенд:** Vanilla HTML5, Modern CSS, JavaScript (ES6+), Lucide Icons, Service Worker (PWA).
- **Контейнеризация:** Docker, Docker Compose, Coolify-ready.

## 📦 Быстрый запуск на сервере (3 шага)

### Шаг 1. Скопируйте файл переменных окружения
```bash
cp .env.example .env
nano .env
```
Заполните пароли и адрес сайта.

### Шаг 2. Запустите стек через Docker Compose
```bash
docker compose up -d
```

### Шаг 3. Инициализируйте базу данных одной командой
```bash
docker compose exec app npm run setup:db
```
Скрипт автоматически создаст все 9 коллекций, наполнит начальные настройки и добавит 4 демонстрационных домика.

Сайт готов! Панель управления доступна по адресу: `https://ваш-домен/admin/login`.

## 🔒 Безопасность

- Доступ к CMS защищен криптографически подписанными `httpOnly` куками.
- Защита от перебора паролей (timing-safe comparison).
- Защита от SSRF при импорте внешних iCal-календарей (проверка DNS и запрет локальных IP).
- Защита заголовков CSP через Helmet, автоматическая конвертация фото в безопасный WebP со сжатием и удалением геометок EXIF.
