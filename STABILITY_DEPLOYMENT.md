# Руководство по развертыванию и поддержанию стабильности

Это руководство описывает процесс развертывания проекта "EcoGorniy" и поддержания его стабильности в продакшн-среде.

## 1. Архитектура

Проект состоит из следующих компонентов:
- **Node.js (Express) бэкенд:** Управляет API, аутентификацией админов, интеграцией с Telegram.
- **Vanilla JS фронтенд:** Разделен на клиентскую часть (бронирование, просмотр) и админ-панель (управление).
- **PocketBase:** Выполняет роль основной базы данных и хранилища файлов.
- **Cloudflare Worker:** Используется как Relay для безопасного получения вебхуков от Telegram и пересылки их на бэкенд.

## 2. Развертывание (Coolify / VPS)

### Бэкенд
1. Используйте Node.js v18+.
2. Настройте все переменные окружения из `.env.example`.
3. Команда запуска: `npm start`.

### База данных (PocketBase)
1. PocketBase можно запустить как отдельный сервис на VPS.
2. Проверьте, что переменные `POCKETBASE_URL`, `POCKETBASE_ADMIN_EMAIL` и `POCKETBASE_ADMIN_PASSWORD` в бэкенде указывают на ваш инстанс PocketBase.
3. Убедитесь, что все коллекции (cabins, bookings, amenities, extra_services, site_settings) созданы и настроены правильно (см. скрипты инициализации или настройте через UI PocketBase).

### Telegram Relay
Для стабильной работы Telegram-ботов с вебхуками рекомендуется использовать Cloudflare Worker, код которого находится в `cloudflare-worker/`. 
Разверните его через Wrangler или интерфейс Cloudflare, указав URL вашего бэкенда.

## 3. Мониторинг и Healthcheck

- `/health` - Возвращает статус 200, если сервер запущен.
- `/ready` - Возвращает статус 200, если сервер подключен к PocketBase и готов принимать запросы.

## 4. Резервное копирование

Регулярно делайте бэкапы данных PocketBase (папка `pb_data`). Это можно автоматизировать с помощью bash-скриптов и cron-задач на сервере.

## 5. Обновления

При выкате обновлений:
1. Сделайте бэкап базы данных.
2. Стяните последние изменения из git.
3. Выполните `npm ci` для чистого обновления зависимостей.
4. Перезапустите Node.js процесс.
5. Проверьте доступность сайта и работоспособность админ-панели.
